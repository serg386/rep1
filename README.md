# Calculator

A clean, modern calculator built with vanilla HTML, CSS, and JavaScript.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Percentage and sign toggle
- Chained operations with running totals
- Expression history shown above the result
- Keyboard support (0-9, operators, Enter, Escape, Backspace)
- Responsive, dark-themed UI

## Usage

Open `index.html` in any modern browser. No build step or dependencies required.
